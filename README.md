# AINeuroScan 🧠

AINeuroScan is an AI-based brain scan analysis system designed to help detect neurological conditions using machine learning and image processing techniques.

## 🚀 Features

- Brain scan analysis
- AI-based prediction system
- User-friendly interface
- Fast processing
- Web-based application

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Machine Learning

## 📂 Project Structure

```bash
AINeuroScan/
│── app.py
│── index.html
│── requirements.txt
│── README.md
```

## ⚙️ Installation

### 1 Clone Repository

```bash
git clone https://github.com/emantalib570-ux/AINeuroScan.git
```

### 2 Open Project Folder

```bash
cd AINeuroScan
```

### 3 Install Requirements

```bash
pip install -r requirements.txt
```

### 4 Run Application

```bash
python app.py
```
